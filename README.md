## 🚀 Como rodar

```bash
git clone https://github.com/higamii/python-portfolio.git
cd python-portfolio
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\\\\Scripts\\\\activate
pip install -r requirements.txt
pytest                           # roda os testes de todos os projetos
```

Cada projeto tem seu próprio README com instruções específicas.
