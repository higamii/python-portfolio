# 01 · Análise de Vendas

Gera dados sintéticos de vendas e produz métricas e gráficos com **pandas** e **matplotlib**.

## Executar
```bash
python analise.py
```
O gráfico é salvo em `output/resumo.png`.

## Testes
```bash
pytest
```

## O que demonstra
- Agregações com `groupby` e períodos mensais
- Dados reproduzíveis com seed
- Funções puras e testáveis separadas do `main()`
